# Changelog

## Phase 1 developer preview — 26 October 2026

Added maintained Swift HTTP service, explicit model-free synthetic adapter,
native service lifecycle, JSON and NDJSON routes, live transport and two-SDK test
harnesses, GitHub CI, Apache-2.0 licensing and contribution/issue templates.

The earlier foundation supplied the grant/scheduler core and source SDKs.
Real inference adapters, offline/model evidence and notarized distribution remain
later phases. See docs/STATUS.md; this is not a production inference release.
