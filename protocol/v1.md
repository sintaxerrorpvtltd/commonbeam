# Protocol 1 — implementation baseline

Frozen for the local foundation on 26 October 2026. Changes to this file and
fixtures require both SDK suites to pass. The HTTP transport uses Hummingbird
2.28.0 and its maintained NIO HTTP parser.

Use only `http://127.0.0.1:<port>`, port 1024–65535. Reject Origin, Cookie,
query strings, nonnumeric Host, duplicate authorization headers, non-JSON bodies,
and unknown request fields. No redirects, proxies, CORS or public admin routes.

Phase 1 includes `fixture-text`, revision 2, backend `synthetic-fixture`, digest null:
an opt-in deterministic test adapter, not an AI model. Normal `local-text` is
unavailable until a real adapter is enabled. Chunked uploads are rejected in this
preview. Responses use JSON or chunked NDJSON and close after completion.

| Route | Contract |
|---|---|
| GET /healthz | `{"service":"commonbeam","protocol":1,"ready":true}`; no inventory |
| GET /v1/capabilities | Authenticated `{protocol:1, profiles:[...]}` |
| POST /v1/text/generate | Grant scope `text.generate`, revision-pinned request |
| POST /v1/requests/{id}/cancel | Owner only; 202 active, 204 terminal, 404 otherwise |

Messages: 1–32, roles system/user/assistant, textual content, aggregate UTF-8
≤65536 bytes. Body ≤98304 bytes. Required fields: profile, profileRevision,
messages. Optional fields: maxOutputTokens (default 256, 1–512), deadlineMs
(default 30000, 1000–120000), stream (default false). Integer fields reject
booleans and fractions. Revisions are positive integers.

Stream: start on admission, zero or more deltas, exactly one done/error/cancelled.
All events share the start ID. Lines ≤131072 bytes, pending/total text ≤262144
bytes. JSON content may be fragmented at any byte, including within UTF-8.
No empty lines, events before start, duplicate start/terminal or unclosed stream.
An empty delta is valid. Additional response fields can be ignored.

Start and complete result carry profile, profileRevision, execution, backend,
modelDigest (nullable). Done carries finishReason stop/length and nullable usage
counts. Error terminal carries the same sanitized error object as HTTP errors.
Client-only errors: protocolMismatch, serviceUnavailable, invalidRequest,
backendProtocolError, cancelled. No automatic generation retries.

The foundation retains at most 256 terminal ownership records; after eviction,
cancel returns 404. This is an explicit bounded-idempotence window.

Error statuses and messages are defined by `BeamError` and fixtures. UI and SDKs
must never display raw provider responses or credentials as errors.
